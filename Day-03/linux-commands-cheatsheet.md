Day-03 Linux Commands cheatsheet

==============================
A. Process Management Commands
==============================

1. ps → running processes dekhne ke liye
ps

2. ps -e → system ke sabhi running processes dekhne ke liye
ps -e

3. ps -ef → detailed process information dekhne ke liye
ps -ef

4. top → live running processes aur CPU/RAM usage dekhne ke liye
top

5. kill PID → kisi process ko stop karne ke liye

Example:
kill 1234

6. kill -9 PID → forcefully process stop karne ke liye

Example:
kill -9 1234

7. htop → advanced live process viewer

(agar installed ho)
htop


==========================
B. File System Commands
==========================

1. ls → files aur folders list karne ke liye
ls

2. cd → directory change karne ke liye

Example:
cd Documents

3. pwd → current location/path dekhne ke liye
pwd

4. mkdir → naya folder banane ke liye

Example:
mkdir practice

5. rm → file delete karne ke liye

Example:
rm demo.txt

6. rm -r → folder delete karne ke liye

(andar files ho tab bhi)
